# Deferred work

These directories are outside the active scanner path:

- [auth](auth/README.md): deferred caller authentication, quota, and associated job handling.
- [report-html](report-html/README.md): deferred HTML rendering.
- `code-scan/`: prototype scouts; [superseded implementations](code-scan/superseded/README.md) are retained separately.

Do not count these features as active security controls or experimentally validated capabilities. Files are retained in place because moving them could invalidate historical references.
