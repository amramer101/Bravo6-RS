# Repository maintenance

This directory records repository organization and publication decisions. It is not a scanner component or a source of experimental ground truth.

- [Repository audit](REPOSITORY_AUDIT.md): findings, completed work, and outstanding documentation work.
- [Publication policy](PUBLICATION_POLICY.md): source visibility, evidence handling, and rights boundaries.
- [Dependency inventory](dependency_inventory.csv): declared runtime and documentation dependencies; this is not a resolved SBOM or license clearance.
- [Initial tracked-file inventory](inventory.csv): path, role, and review status for the 142 tracked files at the start of cleanup; deliberately a baseline, not a live file count.
- [Repository map](../REPOSITORY_MAP.md): current entry points.

Detailed local hashes and history-pattern findings are retained under ignored `output/repository-audit/`. They are not automatically approved for publication.
